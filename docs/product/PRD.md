# PRD: 뛴데이(뛴DAY) 웹앱

## 1. 제품 개요

뛴데이는 부산 공공데이터와 AI를 활용해 개인 맞춤형 러닝·산책 코스를 추천하는 웹앱입니다. 사용자는 현재 위치, 목표 거리, 운동 시간, 체력 수준, 선호 환경, 반려견 동반 여부 등을 입력하거나 자연어로 요청하여 적합한 코스를 추천받을 수 있습니다.

서비스는 단순 운동 기록 앱이 아니라 코스 추천, 드로잉런 생성, 실시간 코칭, 운동 분석, 지역 혜택, ESG 챌린지를 하나의 흐름으로 연결하는 부산 특화 AI 러닝 플랫폼을 목표로 합니다.

## 2. 문제 정의

- 부산의 러닝·산책 가능 공간 정보가 여러 공공데이터와 지도 서비스에 분산되어 있습니다.
- 유명 지역 중심으로 이용이 쏠려 숨은 러닝 인프라가 충분히 활용되지 못합니다.
- 기존 러닝 앱은 기록 측정 중심이고, 지도 서비스는 목적지 길 안내 중심입니다.
- 사용자의 체력, 목적, 시간대, 반려견 동반 여부를 함께 고려하는 추천 경험이 부족합니다.
- 운동 활동이 지역 상권, 관광, 공공정책, ESG 참여로 이어지는 연결 구조가 약합니다.

## 3. 목표

- 부산 공공데이터 기반 러닝·산책 코스 탐색 경험 제공
- AI를 활용한 개인 맞춤형 코스 추천 구현
- 드로잉런 코스 생성으로 재미와 공유성을 강화
- 운동 중 실시간 페이스 가이드 및 경로 이탈 안내 제공
- 운동 후 분석 리포트와 성장 피드백 제공
- 지역 쿠폰, 동백전, 부산 행복 마일리지 등과 연계 가능한 상생 모델 구축
- 플로깅, 탄소 절감량, 배리어프리 챌린지를 통해 ESG 가치 반영

## 4. 주요 사용자

| 사용자 | 니즈 |
| --- | --- |
| 2030 러닝족 | 새로운 코스, 기록 관리, 러닝 크루 공유 |
| 부산 관광객 | 관광지 주변에서 가볍게 걸을 수 있는 코스 |
| 초보 러너 | 체력 수준에 맞는 안전한 코스와 페이스 안내 |
| 반려견 보호자 | 반려견과 함께 이용 가능한 산책 코스 |
| 지역 소상공인 | 코스 이용자를 매장 방문으로 연결하는 홍보 채널 |
| 지자체/공공기관 | 공공데이터 활용, 시민 건강, 지역 활성화 성과 |

## 5. 핵심 사용자 여정

1. 사용자가 웹앱에 접속합니다.
2. 현재 위치 권한을 허용하거나 지역을 선택합니다.
3. 목표 거리, 운동 시간, 강도, 선호 환경, 반려견 동반 여부를 입력합니다.
4. 자연어 요청이 있는 경우 AI가 조건을 추출합니다.
5. AI가 공공데이터와 지도 데이터를 기반으로 추천 코스를 제공합니다.
6. 사용자는 추천 사유, 예상 거리, 소요 시간, 난이도, 편의시설을 확인합니다.
7. 원하는 코스를 선택하고 러닝을 시작합니다.
8. 운동 중 페이스, 경로 이탈, 목표 달성률을 안내받습니다.
9. 운동 종료 후 기록, 탄소 절감량, 배지, 주변 혜택을 확인합니다.
10. 인증 사진 또는 기록을 저장하고 공유합니다.

## 6. 기능 요구사항

### 6.1 홈/지도

- 사용자의 현재 위치 또는 선택 지역을 지도에 표시합니다.
- 추천 코스, 공원, 화장실, 운동기구, 공공시설, 반려동물 동반 가능 장소를 표시합니다.
- 대표 지역 필터를 제공합니다: 강서구 낙동강·생태공원권, 해운대, 광안리, 서면.
- 코스 유형 필터를 제공합니다: 러닝, 산책, 관광, 반려견, 플로깅, 초보자, 드로잉런.

### 6.2 AI 코스 추천

- 자연어 입력을 지원합니다.
- 예시: "오늘 밤 30분 정도 뛰기 좋은 코스 추천해줘"
- AI는 운동 시간, 목표 거리, 강도, 위치, 선호 환경, 반려견 동반 여부를 추출합니다.
- 추천 결과에는 적합도 점수, 추천 사유, 예상 거리, 예상 소요 시간, 난이도, 안전성 정보를 포함합니다.

### 6.3 드로잉런 코스 생성

- 사용자가 거리와 원하는 형태를 선택하면 지도 위에 드로잉런 후보를 생성합니다.
- MVP에서는 샘플 도안 기반 후보를 제공합니다.
- 향후 도로망, 보행 가능 경로, 공원 산책로 데이터를 활용해 실제 주행 가능한 경로로 고도화합니다.
- 예시 도안: 하트, 파도, 강아지, 물고기, 부산 갈매기.

### 6.4 러닝 기록

- 시작, 일시정지, 재개, 종료 기능을 제공합니다.
- GPS 기반 거리, 시간, 평균 페이스, 경로를 기록합니다.
- 코스 이탈 시 알림을 제공합니다.
- 목표 강도 대비 페이스가 빠르거나 느린 경우 안내합니다.

### 6.5 운동 후 피드백

- 운동 결과 요약을 제공합니다.
- 최근 기록 대비 변화량을 제공합니다.
- 예시: "최근 2주간 평균 운동 거리가 15% 증가했습니다."
- 탄소 절감량 리포트를 제공합니다.
- 배지, 완주 인증, 공유 이미지를 제공합니다.

### 6.6 반려견 기능

- 반려견 프로필을 등록할 수 있습니다.
- 견종, 나이, 체중, 산책 빈도, 최근 산책량을 기반으로 권장 산책량을 안내합니다.
- 반려동물 동반 가능 문화시설과 연계한 산책 코스를 추천합니다.

### 6.7 지역 상권/혜택

- 코스 주변 제휴 매장, 쿠폰, 이벤트를 표시합니다.
- 완주 또는 장소 인증 시 혜택을 제공합니다.
- 향후 동백전, 부산 행복 마일리지, 15분 도시 생활권맵과 연계를 고려합니다.

### 6.8 ESG 챌린지

- 랜드마크 플로깅 챌린지를 제공합니다.
- 배리어프리 비대면 러닝 챌린지를 제공합니다.
- 탄소 절감량을 시각화합니다.
- 챌린지 완료 시 배지 또는 포인트를 제공합니다.

## 7. 비기능 요구사항

- 지도 첫 로딩은 3초 이내를 목표로 합니다.
- 추천 결과는 일반 조건 검색 기준 2초 이내, AI 추천 기준 8초 이내를 목표로 합니다.
- 위치정보는 사용자 동의 기반으로만 수집합니다.
- 민감한 건강 정보와 반려견 정보는 최소 수집 원칙을 적용합니다.
- 추천 결과는 공공데이터 기준일과 출처를 표시할 수 있어야 합니다.
- 모바일 웹 사용성을 우선합니다.
- GPS 추적 중 배터리 소모를 최소화합니다.

## 8. MVP 우선순위

### Must

- 지도 기반 코스 탐색
- 공공데이터 기반 코스/시설 표시
- 조건 기반 추천
- AI 자연어 추천 데모
- 코스 상세 정보
- 러닝 시작/종료 및 기록 저장
- 완주 인증

### Should

- 드로잉런 샘플 생성
- 반려견 동반 필터
- 운동 후 피드백
- 탄소 절감량 리포트
- 지역 혜택 카드

### Could

- 음성 코칭
- 실시간 혼잡도 추정
- 러닝 크루 생성
- 소셜 피드
- 구독 결제

## 9. 성공 지표

- 가입 전환율
- 추천 코스 클릭률
- 코스 시작률
- 코스 완주율
- 재방문율
- AI 추천 만족도
- 드로잉런 공유 수
- 지역 혜택 클릭 및 사용 수
- ESG 챌린지 참여 수

## 10. 수익화 방향

- 무료 기본 코스 탐색 및 기록
- 유료 AI 개인화 추천
- 프리미엄 드로잉런 생성
- 건강 상태 기반 코스 추천
- 구독형 분석 리포트
- 지역 상권 광고 및 쿠폰 수수료
- 관광/축제/기관 제휴 코스

## 11. 출시 단계

| 단계 | 범위 |
| --- | --- |
| 1단계 | 공공데이터 기반 지도, 기본 코스, 코스 인증, 편의시설 안내 |
| 2단계 | 사용자 기록, 리뷰, 선호도, 이탈 구간 데이터 수집 및 추천 개선 |
| 3단계 | AI 드로잉런 생성, 실시간 코칭, 개인 분석, 유료 기능 |
| 4단계 | 타 지자체 확장, 관광/축제 연계, 상권 제휴 확대 |
