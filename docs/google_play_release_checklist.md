# 📱 뛴데이 Google Play Store 배포 체크리스트

## 0. 최종 목표

**Google Play Store에 `뛴데이` Android 앱 정식 배포**

전체 진행 순서

```text
개발자 계정 생성
→ 앱 생성
→ 앱 기본정보/정책 설정
→ Release AAB 생성
→ 내부 테스트
→ 비공개 테스트
→ 테스터 12명 이상 14일 유지
→ 프로덕션 액세스 신청
→ Google 심사
→ 정식 출시
```

  - [ ] 조직(Organization)

- [ ] 본인 인증 진행
- [ ] Android 실제 기기를 이용한 개발자 기기 인증 진행
- [ ] Play Console 접속 정상 여부 확인

## 확인할 일

- [ ] 팀원이 아닌 **실제로 장기간 관리할 Google 계정**으로 가입했는가?
- [ ] 계정 아이디/비밀번호를 분실하지 않도록 관리하고 있는가?
- [ ] 개발자 연락 이메일이 실제 확인 가능한 주소인가?
- [ ] 개발자 이름이 향후 앱 스토어에 표시되어도 문제없는 이름인가?
- [ ] 개인 개발자 계정인지 조직 계정인지 최종 확인했는가?

> ⚠️ 2023년 11월 13일 이후 생성된 신규 개인 개발자 계정은 프로덕션 출시 전에 **12명 이상의 테스터가 14일 연속 비공개 테스트에 참여**해야 한다.

# 3. Android 앱 식별정보 확정

## 개발 담당 해야 할 일

- [ ] Android Package Name 확정

예시

```text
com.ddwindae.app
```

- [ ] `applicationId` 확인
- [ ] 앱의 실제 패키지명과 Play Console 등록 대상이 일치하는지 확인
- [ ] 앱 버전명 설정

예시

```text
versionName = 1.0.0
```

- [ ] versionCode 설정

예시

```text
versionCode = 1
```

## 반드시 확인할 일

- [ ] 패키지명이 임시 이름이 아닌가?
- [ ] 패키지명에 테스트용 이름이 남아 있지 않은가?
- [ ] 다른 앱과 충돌하지 않는 패키지명인가?
- [ ] 향후 서비스명 변경 가능성을 고려했는가?
- [ ] versionCode가 정상적으로 증가하도록 설정되어 있는가?

> ⚠️ 패키지명은 배포 이후 앱을 식별하는 핵심 값이므로 출시 직전에 임의 변경하지 않는다.

# 10. Release AAB 생성

Google Play는 Android App Bundle을 이용해 앱을 배포한다.

## 개발 담당 해야 할 일

- [ ] Release Build 생성
- [ ] `.aab` 파일 생성
- [ ] Upload Key 생성
- [ ] Keystore 안전하게 보관
- [ ] Release AAB 서명
- [ ] 빌드 오류 없는지 확인

예시 파일

```text
app-release.aab
```

## 확인할 일

- [ ] Debug Build가 아닌 Release Build인가?
- [ ] `.apk`가 아니라 `.aab` 파일을 준비했는가?
- [ ] Release Signing이 정상 적용되었는가?
- [ ] Keystore를 분실하지 않도록 백업했는가?
- [ ] Keystore 비밀번호를 안전하게 보관했는가?
- [ ] versionCode / versionName이 맞는가?

Google Play 신규 앱에서는 App Bundle 업로드 시 Play App Signing을 사용할 수 있으며, 업데이트 시 `versionCode`는 이전 버전보다 증가해야 한다.

# 14. 테스터에게 전달할 내용

테스터에게 단순히 이메일만 받지 말고 아래 내용을 전달한다.

## 참여 과정

```text
1. 전달받은 Google 계정 확인
2. 비공개 테스트 링크 접속
3. 테스트 참여 선택
4. Google Play에서 뛴데이 설치
5. 앱 실행
6. 주요 기능 사용
7. 14일 동안 테스트 참여 상태 유지
```

## 반드시 안내

- [ ] 테스트용 Google 계정을 변경하지 말 것
- [ ] 14일 동안 테스트 상태를 유지할 것

- [ ] 오류 발견 시 캡처 및 상황 공유

테스터가 중간에 참여를 취소하면 해당 사용자는 연속 14일 조건을 충족하지 못할 수 있다.
